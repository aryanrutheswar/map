1. Executive Summary & Key Deliverables

The React Native Maps Studio began as an interactive Leaflet-based prototyping workbench and has matured into an enterprise-grade geospatial exploration platform. The system bridges web-based interactive visualizers with native React Native mobile mapping engines.

Key Accomplishments:
  • Whole World Starting Canvas: Initial world view without tile multiplication or unwanted automatic location locking.
  • Strict Local Area Scoping: Completely eliminated worldwide pin clutter when exploring specific locations (e.g. Chittoor, Tirupati, Bengaluru).
  • Verified Chittoor Local Dataset: 28 landmark destinations across 6 categories (Temples, Hotels, Cafes, Parks, Malls, Tourist Sights) with real distance calculations.
  • Interactive 2-Press Routing Engine: Double-click origin + destination, real OSRM road graph fetching, animated driving simulation, and travel telemetry HUD.
  • Flexible Place Selection: Dedicated "Select Place" modal with 1-click popular cities, search-as-you-type, and direct click-anywhere-on-map selection.
  • Cross-Platform Code Export: 1-click embed code for Web (iFrame), React Native WebView, and Native react-native-maps SDK.

6. Interactive 2-Press Driving Route Engine

Users can double-click any two points on the map to calculate a live driving route and watch an animated vehicle drive along the road network.

Navigation Workflow:
  1. Double-Click Location 1: Drops Point A (🟢 Start Marker).
  2. Double-Click Location 2: Drops Point B (🏁 Destination Marker).
  3. OSRM Routing: Calls OSRM Driving API to fetch real roadway geometries.
  4. Polyline Rendering: Renders a dual-layer polyline (cyan casing + sky blue core).
  5. Telemetry HUD: Displays distance (km) and estimated drive time (mins).
  6. Animated Car: A 🚗 vehicle marker moves along the route coordinates, rotating smoothly based on segment bearing angles.
  7. Controls: Provides Pause/Resume, Replay, and 1x/2x/4x Speed toggles.

7. Place Selection Engine (No Home Auto-Lock)

Previously, the browser was automatically executing geolocation on load, which hijacked the map view and zoomed into where the user lives. This has been resolved with a dedicated multi-modal place selection system:

  • No Auto-Location Override: Geolocation is strictly on-demand when the user clicks My Location.
  • Dedicated "Select Place" Button & Modal: Located in both the top bar and category filter bar.
  • 1-Click Quick Cities: Direct access cards for Chittoor, Tirupati, Bengaluru, Chennai, Hyderabad, Mumbai, and Delhi.
  • Click Anywhere on Map to Select: Tapping any location on the map drops an interactive pin, performs reverse geocoding, and shows a ✨ Show Nearby Spots action button.

8. Code Walkthrough & Key Algorithms

A. Haversine Distance Calculation (app.js)

function calculateDistanceKm(lat1, lon1, lat2, lon2) {
  const R = 6371; // Earth radius in km
  const dLat = (lat2 - lat1) * Math.PI / 180;
  const dLon = (lon2 - lon1) * Math.PI / 180;
  const a = 
    Math.sin(dLat/2) * Math.sin(dLat/2) +
    Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) * 
    Math.sin(dLon/2) * Math.sin(dLon/2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
  return R * c;
}

B. Interactive Map-Click Place Selection (app.js)

map.on('click', async (e) => {
  if (activeTool === 'marker' || activeTool === 'geofence') return;

  const lat = e.latlng.lat;
  const lng = e.latlng.lng;

  if (!selectionMarker) {
    selectionMarker = L.marker([lat, lng], { icon: selectionPinIcon, zIndexOffset: 1200 }).addTo(map);
  } else {
    selectionMarker.setLatLng([lat, lng]);
  }

  const fullAddr = await reverseGeocode(lat, lng);
  const cityName = fullAddr.split(',')[0].trim() || 'Selected Location';

  const popupContent = document.createElement('div');
  popupContent.className = 'selected-place-popup';
  popupContent.innerHTML = `
    <div class="selected-place-badge">📍 Selected Location</div>
    <div class="selected-place-name">${escapeHTML(fullAddr)}</div>
    <button class="select-place-explore-btn">✨ Show Nearby Spots in ${escapeHTML(cityName)}</button>
  `;

  popupContent.querySelector('.select-place-explore-btn').addEventListener('click', () => {
    focusOnArea(cityName, lat, lng, 14, 25);
    exploreDrawer.classList.add('open');
  });

  selectionMarker.bindPopup(popupContent).openPopup();
});

C. 2-Press Driving Navigation Handler (app.js)

function handleLocationPress(latlng) {
  if (!routeStartMarker) {
    routeStartMarker = createRoutePointMarker(latlng, 'A');
    showToast('Origin set! Double-click destination to create route.');
  } else if (!routeEndMarker) {
    routeEndMarker = createRoutePointMarker(latlng, 'B');
    calculateAndDrawRoute(routeStartMarker.getLatLng(), latlng);
  } else {
    clearTravelRoute(false);
    routeStartMarker = createRoutePointMarker(latlng, 'A');
    showToast('New start set! Double-click destination to create route.');
  }
}

map.on('dblclick', (e) => {
  handleLocationPress(e.latlng);
});

9. Bugs Diagnosed & Engineering Resolutions

1. Worldwide Pin Leak into Local Views
Problem: Hardcoded pins for Paris, Tokyo, and New York were rendering even when the user moved to Chittoor.
Solution: Implemented geodetic radius filtering (dist <= radiusKm) inside renderPOIs() and replaced static mock pins with the verified Chittoor dataset.
2. Automatic Home Location Hijack
Problem: On page load, the browser immediately ran GPS geolocation and flew to the user's home.
Solution: Removed automatic startLiveLocationTracking() from script execution; geolocation is now strictly triggered on user click.
3. Horizontal World Duplication
Problem: Leaflet was wrapping the world horizontally, showing duplicate copies of continents.
Solution: Set noWrap: true on all tile layers and locked map bounds to L.latLngBounds([-85, -180], [85, 180]).
4. Vercel 404 Routing Error
Problem: Vercel was unable to resolve root static files.
Solution: Added vercel.json rewrites mapping root routes directly to /index.html.

10. User Testing & Verification Guide

  1. Open Map: Navigate to http://localhost:3000. Verify the map opens to a clean world view without auto-locating your home.
  2. Explore Chittoor: Click 📍 Chittoor Spots in the filter bar. The camera flies to Chittoor and displays 28 local landmarks.
  3. Filter Categories: Click 🛕 Temples or 🏨 Hotels. Only Chittoor-area places are shown with real distance badges.
  4. Select Any Other Place: Click 📍 Select Place in the header, choose Tirupati or Bengaluru. Only spots in that city appear.
  5. Click on Map: Click anywhere on the map. A pin drops with location details and a ✨ Show Nearby Spots action.
  6. Plan a Route: Double-click any two points on the map. Watch the OSRM route render and the animated car travel along the road.
